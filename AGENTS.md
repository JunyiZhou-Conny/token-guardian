# Token Guardian agent guidance

Use [CLAUDE.md](CLAUDE.md) for this repository's current contributor and agent
guidance. The repository is
[JunyiZhou-Conny/token-guardian](https://github.com/JunyiZhou-Conny/token-guardian),
a local source prototype built on TokenTracker, initially focused on macOS.

Read [README.md](README.md), [GUARDIAN.md](GUARDIAN.md), and the relevant source
before changing behavior. Keep usage evidence, attribution limits, privacy, and
reported versus estimated costs visible. Preserve source and artwork notices.

The verbatim inherited guidance is retained in
[AGENTS.upstream.md](AGENTS.upstream.md) and [CLAUDE.upstream.md](CLAUDE.upstream.md)
for historical architecture reference only. Its release commands, InsForge
project, hosted endpoints, npm package, and Homebrew operations belong to the
original upstream project. No Guardian release pipeline or cloud backend is
configured; do not deploy to the original services based on those archived files.
